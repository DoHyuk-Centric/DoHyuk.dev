이 블로그를 시작하며 남기는 첫 글입니다.

코드 블록 스타일을 확인하기 위한 샘플입니다.

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="utf-8" />
    <title>DoHyuk.dev</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>
```

```css
.card {
  display: flex;
  padding: 24px;
  border-radius: 6px;
  background-color: var(--bg-white);
}
```

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("DoHyuk"));
```

```typescript
type Post = {
  title: string;
  createdAt: string;
};

function formatPost(post: Post): string {
  return `${post.title} (${post.createdAt})`;
}
```
